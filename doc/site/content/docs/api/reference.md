## Kotlin & JS reference

The reference of every public class and function of the core (`core`), of the causality solver, of the parallel solver
and of the npm package `@tuprolog/arg2p`, generated by [Dokka](https://kotlinlang.org/docs/dokka-introduction.html) from
their KDoc. The declarations usable from JavaScript are those exported to it (`Arg2p`, `Flags`, the clusters, ...: see
